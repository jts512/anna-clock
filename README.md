# Anna's Countdown

A small, stylized countdown page celebrating Anna finishing her Pathology Assistant program at Rosalind Franklin University.

## Details

- Start date: May 17, 2026
- End date: May 17, 2028
- Countdown includes:
  - Years
  - Months
  - Days
  - Hours
  - Minutes
  - Seconds
- Includes a live progress bar showing percentage complete

## Run locally

From this project folder, start a simple local server:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Project files

- `index.html` — page structure
- `styles.css` — styling and layout
- `script.js` — countdown logic and progress calculation

## Notes

This is a lightweight static webpage built with HTML, CSS, and JavaScript.
